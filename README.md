# JARVIS 3D — Central de Comando

Versão web do JARVIS 3D (globo holográfico, Supervisor Victor em 3D, microfone neon e painéis).

- Abra no computador ou no iPhone (Safari) pelo endereço do GitHub Pages deste repositório.
- No iPhone: Compartilhar → "Adicionar à Tela de Início" para abrir em tela cheia, como um app.
- Os painéis mostram a etiqueta **EXEMPLO** enquanto o n8n não estiver conectado neste aparelho
  (Configurações → URL do n8n e token; o token fica salvo só no próprio navegador, nunca neste site).

Créditos dos dados do globo: NASA Earth at Night e Blue Marble (domínio público); cidades GeoNames (CC BY 4.0).
